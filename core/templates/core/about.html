About DevTrack

DevTrack is a project and task management application built with Django. It helps users organize projects, manage tasks, and track their progress in one place.

What is DevTrack?

DevTrack was created as a learning project to explore how a real-world web application can be designed using Django and a relational database.

The application demonstrates authentication, authorization, database relationships, CRUD operations, forms, templates, and Django's ORM.

Features

🔐 Authentication

Users can register, log in, and securely access their own projects.

📁 Project Management

Create, edit, view, and delete projects.

✓ Task Management

Create tasks, update them, delete them, and track completion status.

🗄️ Database

Uses Django ORM with SQLite to manage users, projects, and tasks.

Technology Stack

Backend: Python & Django

Database: SQLite

Frontend: HTML & CSS

Architecture: Django MVT
